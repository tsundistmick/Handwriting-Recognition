# 📊 Анализ и визуализация результатов распознавания рукописных цифр и текста

Аналитическая часть проекта по исследованию нейросетевых моделей для OCR.  
Включает:
- Сравнение baseline-моделей с нейросетевыми решениями
- Визуализацию ошибок и матриц ошибок
- Статистический анализ качества распознавания

---

## 📁 Файлы аналитики

| Файл | Описание |
|:---|:---|
| `digit/digit_analytic.ipynb` | Анализ MNIST: визуализация данных, обучение Softmax и CNN, матрицы ошибок |

## 🧠 1. Распознавание цифр (MNIST)

### Данные
- **Обучающая выборка:** 50 000 изображений 28×28
- **Тестовая выборка:** 10 000 изображений 28×28
- **Классы:** 10 (цифры 0–9)

### Модели

#### Softmax-регрессия (baseline)
- Реализована с нуля на NumPy (градиентный спуск)
- Сравнение с `sklearn.LogisticRegression`
- **Точность:** ~92.1%

#### Свёрточная нейросеть (CNN)
- Архитектура: 2 свёрточных блока + полносвязный классификатор
- **Точность:** **99.54%** (на тестовой выборке)

### Визуализация
- **Примеры цифр:** 25 случайных изображений из обучающей выборки
- **Распределение классов:** гистограммы для train и test
- **Матрицы ошибок:**
  - Softmax-регрессия (без диагонали)
  - CNN (без диагонали)
- **Кривые обучения:** динамика loss и accuracy по эпохам

### Ключевые наблюдения
- Основные ошибки CNN: путаница пар **5↔3**, **4↔9**, **6↔0**
- Разрыв между train и test accuracy минимален (<0.1%) — переобучение отсутствует
- Быстрая сходимость: 98.7% accuracy уже на 1-й эпохе

## 📝 2. Распознавание текста (IAM)

### Данные
- **Авторов:** 657
- **Строк текста:** ~13 353
- **Алфавит:** 72 символа (a–z, A–Z, 0–9, знаки препинания, пробел)
- **Формат:** Изображения переменной ширины, высота нормирована к 64px

### Модели

#### Tesseract (baseline)
- Классический OCR-движок (без дообучения на IAM)
- **CER:** ~51% (средний по выборке)
- **WER:** ~93%

#### CRNN + CTC (наша модель)
- Архитектура: CNN-экстрактор → BiLSTM → CTC
- **CER (Greedy):** 6.61%
- **CER (Beam Search + LM):** **6.56%**

### Визуализация
- **Гистограмма CER** для Tesseract и CRNN
- **Кривые обучения:** динамика loss и CER по эпохам
- **Топ-10 ошибок (замены символов)** для Tesseract и CRNN
- **Худшие распознавания:** примеры с наибольшим CER

### Анализ ошибок CRNN
- **Средний CER:** 8.1%
- **Медианный CER:** 6.2%
- **Минимальный CER:** 1.5%
- **Максимальный CER:** 55.9%

**Топ-5 частых ошибок:**
| Ожидаемый символ | Предсказанный символ | Количество |
|:---:|:---:|:---:|
| e | пробел | 383 |
| t | пробел | 312 |
| пробел | t | 303 |
| пробел | a | 268 |
| пробел | e | 257 |

**Худшие распознавания:**
| Оригинал | Предсказание | CER |
|:---|:---|:---:|
| Junior Medical Officer ... | rwice marce oficer ... | 55.9% |
| suppose , to meet me ... | SPPOTE , Po meET me ... | 50.9% |
| of variety and it 's a change ... | of VErs An irs A AnE ... | 46.6% |

### Ключевые наблюдения
- Большинство ошибок — замены символов на пробел
- Языковая модель (BigramLM) дала улучшение CER на 0.04%
